Cloud Carbon Footprint (CCF) Estimation Methodology

GreenOps Standard

Carbon footprint is estimated using the open-source Cloud Carbon Footprint scientific model adapted for AWS Sydney (ap-southeast-2):

Power (W) = 2 vCPUs × [0.74W + (CPU% / 100) × (3.5W - 0.74W)]
Energy (kWh/h) = (Power in W / 1000) × 1.135 (AWS PUE)
Emissions (gCO2e/h) = Energy (kWh/h) × 640 gCO2e/kWh (NSW Grid Factor, NGA 2025)

All carbon numbers are calibrated estimates for student sustainability research. New EC2 instances take 5-10 minutes for CloudWatch metrics to propagate.
